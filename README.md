  StudentHub Portal

A simple Student Management Portal website developed using **HTML, CSS, and JavaScript**. This project provides different pages for students such as login, dashboard, attendance, courses, assignments, results, profile, and contact information.

---

  How to Run

1. Download or clone the project.
2. Open the project folder in **Visual Studio Code**.
3. Open the **pages** folder.
4. Run **index.html** using:
   - Live Server (Recommended)
   - Or open it directly in your web browser.
